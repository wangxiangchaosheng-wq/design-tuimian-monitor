# 985 / 211 高校设计类预推免监测器（2027届）

这是一个面向设计学、信息艺术交互、工业设计、环境设计、数字媒体、建筑、城乡规划与风景园林等方向的官方信息监测器。

## 当前版本的核心逻辑

- 监控 39 所原“985工程”高校，并增加首批 12 所设计类重点 211 高校入口。
- 识别“接收外校推荐免试 / 推免预报名 / 预选拔”通知。
- 排除“校内推荐资格、推免工作细则、拟推荐名单、推荐名额”等容易误报的页面。
- 自动抽取并保存：院校等级、学校、学院、专业方向、报名起止时间、考核方式、公告链接、报名系统、申请材料、跨专业说明和核验状态。
- 专业方向、考核方式、申请材料统一输出为 `1. 2. 3.` 编号清单。
- 数据按“院校等级 → 学校 → 截止时间”排序，因此同一学校始终相邻。
- 生成 `data/notices.csv`、`data/notices.json` 和分校归组的 `docs/index.html`。
- GitHub Actions 默认每 4 小时更新一次；发现新增或正文变化时，可选发送 Webhook。

> 高校官网没有统一实时推送 API，本项目采用低频、合规的近实时轮询。自动抽取用于发现和整理，提交申请前仍须打开官方公告逐项复核。

## Excel 文件

项目根目录中的 `985与211设计类预推免监测表_2027_UX重构版.xlsx` 由本项目 `data/notices.csv` 的结构化输出生成。它不是图片，包含：

- `985院校`：同校纵向合并，学校之间粗分割线，单元格之间细线。
- `211院校`：与 985 表相同的交互和视觉规则。
- `爬虫数据源`：不合并的原始结构化数据，便于筛选和审计。
- `使用说明`：字段、排序、倒计时与更新逻辑。

倒计时使用 Excel 的 `NOW()` 公式自动计算，并以红色加粗显示。

## 本地运行

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python crawler.py
```

只用已人工核验的详细种子数据生成输出，不访问网络：

```bash
python crawler.py --seed-only
```

打开 `docs/index.html` 可查看自动更新的网页表格。

## 部署为自动更新网页

1. 把整个文件夹上传到 GitHub 仓库。
2. 在仓库 **Actions** 页面允许工作流运行。
3. 在 **Settings → Pages** 中选择从 `main` 分支的 `/docs` 目录发布。
4. 工作流每 4 小时抓取一次，并把 `data` 和 `docs` 的变化提交回仓库。
5. 需要飞书、企业微信或自建服务提醒时，在仓库 Secrets 中添加 `WEBHOOK_URL`。

## 关键文件

- `config/schools.json`：985 / 211 官方入口与重点学院配置。
- `data/notices_seed_detailed.json`：已人工核验的详细初始通知，材料和专业均保留条目结构。
- `data/notices.csv`：爬虫统一输出，也是 Excel 展示表的数据源。
- `crawler.py`：抓取、分类、分段提取、编号、去重、排序与网页生成。
- `.github/workflows/update.yml`：每 4 小时自动运行。
- `docs/index.html`：同校归组的在线监测表。

## 抽取与合规边界

- 默认请求间隔不低于 0.8 秒，建议保持 1.3 秒以上。
- 不绕过验证码、登录、访问控制或反爬机制。
- 单入口默认最多抓取 18 个候选页面，只跟进一层链接。
- 保留网页换行结构，以识别官网原有编号和申请材料条目。
- 标记“待人工核验”的字段不得直接用于提交申请。
